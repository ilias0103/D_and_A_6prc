Контрольные вопросы:

7. Что такое адаптивная вёрстка?
Ответ: Это подход, при котором внешний вид сайта изменяется в зависимости от размера экрана устройства.

8. Для чего используются media queries?
Ответ: Для применения разных CSS-стилей при определённых условиях, например при определённой ширине экрана.

9. Разница между max-width и min-width?
Ответ: max-width задаёт условие для экранов не шире указанного значения, а min-width — для экранов не уже указанного значения.

10. Что такое breakpoints?
Ответ: Это точки изменения макета, при которых применяются другие стили для разных размеров экранов.

11. Почему важен meta viewport?
Ответ: Он сообщает браузеру мобильного устройства, как масштабировать страницу и использовать ширину экрана.

12. Как Grid помогает адаптивности?
Ответ: Grid позволяет менять количество колонок через media queries, например с 3 на 2 и затем на 1.

13. Как Flexbox используется в адаптивной вёрстке?
Ответ: Flexbox позволяет менять направление и расположение элементов в зависимости от размера экрана.

14. Можно ли использовать несколько media queries?
Ответ: Да, можно использовать несколько media queries для разных breakpoints.

15. Что будет без viewport meta?
Ответ: На мобильном устройстве страница может отображаться уменьшенной и некорректно масштабироваться.

16. Разница адаптивного и отзывчивого дизайна?
Ответ: Адаптивный дизайн использует заранее заданные варианты макета для разных размеров экранов, а отзывчивый дизайн гибко подстраивается под доступное пространство.
